Q1. Why must every <label> have a for attribute that matches an input's id? Write a correct label-input pair from memory

Ans: Clicking the label focuses the input which is key for accessibility

<label for="Address">House Address</label>
<input type="Address" id="Address"="Adress" required />

type=password hides text
